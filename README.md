# 🧵 Threadly – Fashion E-Commerce Website

Threadly is a modern and responsive **fashion e-commerce website** designed to provide users with a smooth online shopping experience. The website includes product browsing, shopping cart functionality, wishlist management, and multiple informational pages.

The project was built using **HTML, CSS, and JavaScript**, with a focus on responsive design, interactive features, and a clean fashion-oriented user interface.

## ✨ Features

* 🏠 **Home Page** – Attractive landing page showcasing the brand and featured products.
* 🛍️ **Shop Page** – Browse and explore available clothing products.
* 🔎 **Product Display** – View products with relevant details and pricing.
* 🛒 **Shopping Cart** – Add products to the cart and manage selected items.
* ❤️ **Wishlist** – Save favorite products for later.
* 📖 **About Page** – Information about the Threadly brand.
* 📩 **Contact Page** – Contact section for customer inquiries.
* 📱 **Responsive Design** – Designed to work across desktop, tablet, and mobile screen sizes.
* ⚡ **Interactive UI** – JavaScript is used to provide dynamic shopping interactions.
* 🎨 **Modern Fashion UI** – Clean and visually appealing design suitable for a clothing brand.

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic elements
* **CSS3** – Styling, layouts, responsiveness, and visual design
* **JavaScript** – Dynamic functionality and user interactions
* **VS Code** – Development environment
* **Git & GitHub** – Version control and project hosting

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/nitiksharwt/threadly.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd threadly
```

### 3. Run the website

Open `index.html` in your browser.

For the best development experience, you can use the **Live Server extension in VS Code**.
